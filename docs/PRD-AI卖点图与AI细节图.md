## 1. 名词约定

| 术语 | 含义 |
| --- | --- |
| 积分 | 平台统一计费单位，与生视频等业务共用同一余额账户与明细账户 |
| 张数 | 单次提交生成图片的数量，档位固定 1 / 2 / 4 |
| 语种数 | 卖点图特有维度，所选文案语言的数量，1～9 |
| 出图总量 | 实际交付给用户的图片总数 = 张数 × 语种数（卖点图）／张数（细节图） |

## 2. 背景与目标

### 2.1 业务背景

AI图片创作已上线换背景、白底图、去水印、局部消除、一键生图、电商套图等工具。但在「单品精修」链路中存在两个明显缺口：

1. **上架缺卖点主图**：商家手上有商品图，但没有文案能力，无法把「续航 48 小时、IPX7 防水」这类卖点排版成营销主图，跨境卖家还额外需要多语种版本。
2. **详情页缺细节图**：详情页要证明品质，需要材质、工艺、接缝等特写，但普通手机拍摄放大后糊、杂质多，无法直接上架。

因此新增两个工具页：**AI卖点图**（文字+图片合成能力）与 **AI细节图**（图像增强+局部特写能力）。

### 2.2 产品目标

| 目标 | 说明 |
| --- | --- |
| 一次产出可上架的主图 | 用户仅需上传 1 张商品图，即可得到带卖点文案的成品主图，无需设计能力 |
| 支撑跨境多语种场景 | 卖点文案按目标市场语种输出，覆盖东南亚 / 中东 / 日韩等主力出海市场 |
| 细节图品质证明 | 输出清晰可放大、可用于详情页的材质工艺特写 |

### 2.3 与其他工具的能力边界（避免重复建设）

| 工具 | 边界 |
| --- | --- |
| AI卖点图 | **单品精修**：围绕单商品做卖点文案排版，输出单张成品主图（可多张/多语种） |
| 电商套图 | **整店批量**：按平台规范一次性输出整套上架图（含白底/场景/卖点/尺寸等模块） |
| 一键生图 | **批量粗加工**：一次勾选多种类型批量出图，不做单类型深度精修 |
| AI细节图 | **细节特写**：只做局部放大与细节呈现，不做文案排版 |

> 依赖关系：AI卖点图与电商套图的「卖点信息图」模块能力相似，前者为精修单图、后者为套图模块，需共用同一套文案生成能力，差异仅在输出规格与排版模板。

## 3. 通用规范（两个页面共用）

### 3.1 入口与信息架构

| 项 | 规格 |
| --- | --- |
| 一级入口 | AI视频创作 / **AI图片创作** / 多语言翻译 / 商机选品 / 出海贸易 / 店铺经营 |
| 二级入口 | AI图片创作页左侧工具列表（rail），点击条目即切换右侧页面 |
| 工具列表顺序 | 白底图 → 去水印 → 局部消除 → **AI卖点图** → **AI细节图** → 试穿试用 → 商品换色 → AI商品标尺图 → 一键生图 → 电商套图 |
| 切换方式 | 单页应用（SPA），点击即切换，不跳转新页面、不丢失全局状态 |
| 默认进入 | 进入 AI图片创作时默认停在上次停留的工具页 |

### 3.2 页面布局

┌──────────────────────────────────────────────────────────┐
│  顶部导航（积分余额 / 充值入口 等全局元素）                 │
├────────┬──────────────────────────┬──────────────────────┤

| 区域 | 规格 |
| --- | --- |
| 工具列表（rail） | 图标 + 名称，选中态高亮；移动端吸附左侧 |
| 操作面板 | 宽度自适应，内容区垂直滚动，底部操作栏固定不随内容滚动 |
| 预览画布 | 展示该工具的效果预览卡（tag + 标题 + 副说明 + 示例图 + 对比角标） |
| 移动端 | 宽度 ≤ 768px 时**隐藏右侧预览画布**，操作面板变为浮层（左偏移 52px，顶部固定，带阴影） |

### 3.3 字段区组件规范

所有字段统一由「字段头 + 说明小字 + 选项区」三部分组成，顺序固定：

| 元素 | 规格 |
| --- | --- |
| 字段头 | 字段名称；必填字段名称前显示红色星标（`req`） |
| 字段限定语 | 字段名后接灰色小字补充语义，如「生成张数**（每种语种）**」「文案语种**（可多选）**」 |
| 说明小字 | 位于**字段名下方、选项上方**（不得放在选项下方），灰色小字，用于解释规则 |
| 选项区 | 多选组：标签可任意组合，可全部取消；单选组：始终保留 1 个选中；计数组（张数）：始终保留 1 个选中 |

### 3.4 上传组件规范

| 项 | 规格 |
| --- | --- |
| 上传数量 | 商品图 **仅支持 1 张**（本页所有工具一致） |
| 计数显示 | 字段头右侧显示 `(0/1张)`，上传后变 `(1/1张)` |
| 支持格式 | JPG / JPEG / PNG |
| 单张大小 | ≤ 25MB |
| 最小尺寸 | ≥ 300px（任一边） |
| 提示文案 | `支持上传JPG/JPEG/PNG格式图片，单张大小25MB以内，尺寸不小于300px` |
| 上传后 | 显示缩略图 + 文件名 + 右上角「×」移除按钮；再次点击上传区不重复添加 |
| 移除 | 点击「×」清空，计数回到 0，同时清空上一次的完成提示 |
| 未上传即提交 | 上传区抖动提示（约 0.4s）并阻止提交，不弹窗、不扣分 |
| 校验失败 | 需给出明确原因（格式不支持 / 超出大小 / 尺寸过小），**原型阶段为示意，研发需补齐真实校验与错误提示** |

### 3.5 底部操作栏

| 元素 | 规格 |
| --- | --- |
| 左侧标题 | 「处理内容」 |
| 左侧摘要 | 动态文本，随张数/语种/比例/选项实时刷新，格式见各页面章节 |
| 开始按钮 | 文案「开始处理」，按钮内嵌积分徽标显示本次消耗积分 |
| 处理中 | 按钮置灰不可重复点击，文字变「处理中…」，前置转圈图标 |
| 完成后 | 摘要右侧追加绿色完成提示，按钮恢复可点 |

### 3.6 状态机

```
待上传 ──上传成功──▶ 可提交 ──点击开始──▶ 处理中 ──成功──▶ 已完成
   ▲                    │                    │
   └──移除图片───────────┘                    └──余额不足──▶ 引导充值
                                              └──提交失败──▶ 回退可提交（退分）
```

| 状态 | 表现 |
| --- | --- |
| 待上传 | 摘要与积分徽标已按默认值显示；点击开始 → 上传区抖动 |
| 可提交 | 所有交互可点，积分实时联动 |
| 处理中 | 按钮 busy，禁止重复提交，其余控件保持可点但提交无效 |
| 已完成 | 显示完成提示与本次积分，可立即再次提交 |
| 余额不足 | 弹确认框：「当前积分不足，本次处理需要 X 积分，您当前余额 Y 积分，还差 Z 积分。点击「确定」前往充值。」→ 确定跳转充值中心，取消留在当前页 |

### 3.7 积分与明细规范

| 项 | 规格 |
| --- | --- |
| 余额账户 | 与生视频、其他图片工具**共用同一账户**，键 `wb_credits_v1` |
| 明细账户 | 键 `wb_credit_log`，最多保留 200 条，最新在前 |
| 明细结构 | `{ t: ISO时间, type: 'minus', v: -积分, name: 工具名, detail: 描述文案 }` |
| 扣分时机 | 点击开始 → 校验通过 → 立即扣分（处理中态） |
| 失败返还 | 生成失败须原路返还并写入 `refund` 类型明细「已返还 X 积分」 |
| 扣分描述 | 各页面专属格式见第 4.4 / 5.4 节 |

### 3.8 响应式断点

| 断点 | 表现 |
| --- | --- |
| > 1200px | 工具列表 + 操作面板 + 预览画布 三栏 |
| 960 ~ 1200px | 三栏，预览画布缩放 |
| ≤ 960px | 面板内边距收窄至 16px |
| ≤ 768px | 隐藏预览画布；操作面板变浮层 |

| 430px 窄屏 | 无横向滚动条、选项标签可换行、底部按钮不遮挡内容 |

## 4. AI卖点图 页面需求

### 4.1 页面定位

| 项 | 文案 |
| --- | --- |
| 页头标题 | AI卖点图 |
| 页头副标题 | 自动提炼卖点文案，排版生成营销主图 |
| 预览卡 tag | AI卖点图 |
| 预览卡标题 | 一图讲清卖点 |
| 预览卡副说明 | 多语种文案 · 排版上图 |
| 预览卡角标 | 左：商品图（深色）／右：卖点成图（浅色） |

**一句话定位**：上传 1 张商品图，AI 自动提炼卖点并排版成可上架的营销主图，支持多语种、多张批量输出。

### 4.2 字段清单

| # | 字段名 | 必填 | 组件类型 | 默认值 | 计费影响 |
| --- | --- | --- | --- | --- | --- |
| 1 | 商品图片 | 是 | 单图上传 | 空 | 无 |
| 2 | 卖点类型 | 标注必填（实际可不选） | 多选标签 | 全不选 | 无 |
| 3 | 卖点关键词 | 否 | 多行文本（2 行） | 空 | 无 |
| 4 | 生图比例 | 是 | 单选标签 | 1:1 | 无 |
| 5 | 生成张数 | 是 | 单选（计数组） | 1张 | **倍数** |
| 6 | 文案语种 | 是（至少 1） | 多选标签 | 中文 | **倍数** |

> 字段展示顺序即为上表顺序（商品图片 → 卖点类型 → 卖点关键词 → 生图比例 → 生成张数 → 文案语种），**不得调整**（张数与语种相邻易混淆，已刻意把语种放最后）。

### 4.3 字段详解

#### 4.3.1 商品图片
- 规格同「3.4 上传组件规范」。
- 上传后 AI 需识别商品主体、类目、主色调，作为文案生成与排版底图。

#### 4.3.2 卖点类型（多选）
- 选项（6 项）：`核心功能` / `性能优势` / `材质工艺` / `设计亮点` / `使用场景` / `促销活动`
- 说明文案：`可多选，AI 将围绕所选类型提炼卖点并排版上图；不选则自动识别`
- 规则：
  - 可多选、可全部取消；**全部未选时语义为「由 AI 自动识别卖点方向」**，不阻断提交。
  - 该字段**不影响积分**（卖点图走固定单价，不按类型数加价）。
- 研发注意：字段名带必填星标，但业务上允许为空，实现时按「可为空，空 = 自动识别」处理，勿做前端强校验。

#### 4.3.3 卖点关键词（选填）
- 组件：多行文本，默认 2 行高度，可自适应。
- 占位符：`描述商品卖点，如「续航 48 小时 · IPX7 防水 · 一年换新」，留空则由 AI 自动提炼`
- 规则：填写时该内容优先级高于 AI 自动提炼；建议限制 200 字以内（原型未限制，研发需补充字数上限与实时计数提示）。

#### 4.3.4 生图比例（单选）
- 选项（5 档）：`1:1`（默认） / `4:3` / `3:4` / `16:9` / `9:16`
- 说明文案：`1:1 平台主图 · 4:3 详情页横图 · 3:4 竖版主图 / 详情首屏 · 16:9 横幅 · 9:16 短视频封面`
- 规则：单选，**始终保留 1 个选中**（不可取消到无选中态）；切换不额外计费。

#### 4.3.5 生成张数（单选）
- 字段名带限定语：`生成张数` + 灰字 `（每种语种）`
- 选项（3 档）：`1张`（默认） / `2张` / `4张`
- 说明文案：`可一次输出多张不同构图 或 卖点组合的商品图`
- 语义：**每个语种**各生成所选张数。例：选「2张 + 中文/英语」时，中文出 2 张、英文出 2 张，共 4 张。
- 说明小字中**禁止出现单价话术**（如「单张 10 积分」），价格只在按钮徽标与摘要中体现。

#### 4.3.6 文案语种（多选）
- 字段名带限定语：`文案语种` + 灰字 `（可多选）`
- 选项（9 项）：`中文`（默认选中） / `英语` / `阿拉伯语` / `泰语` / `印尼语` / `越南语` / `韩语` / `马来语` / `蒙古语`
- 说明文案：`按所选语言输出整套卖点图，按「张数 × 语种数」计`
- 字段头右侧实时计数：`已选 N 个语种 · 共出图 N 张`（共出图 = 张数 × 语种数）
- 规则：
  - **至少保留 1 个语种**：取消最后一个时抖动提示并保持选中（不做弹窗）。
  - 与视频翻译的语种口径保持一致。

### 4.4 计费与文案

| 项 | 内容 |
| --- | --- |
| 公式 | `积分 = 10 × 生成张数 × 语种数` |
| 单张单价 | 10 积分 / 张 / 语种 |
| 底部摘要 | `N 张 × N 语种 · 共 X 积分` |
| 按钮徽标 | X（同摘要） |
| 完成提示 | `已生成 N 张图（N 张 × N 语种）· 已扣 X 积分` |
| 明细描述 | `AI卖点图 N 张 × N 语种 · 比例 · X 积分` |

**计费示例**

| 上传 | 卖点类型 | 比例 | 张数 | 语种 | 出图总量 | 消耗积分 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 张 | 核心功能 | 1:1 | 1张 | 中文 | 1 张 | **10** |
| 1 张 | 核心功能 + 材质工艺 | 16:9 | 2张 | 中文 + 英语 | 4 张 | **40** |
| 1 张 | 全不选（自动识别） | 3:4 | 4张 | 中文 + 英语 | 8 张 | **80** |
| 1 张 | 促销活动 | 9:16 | 2张 | 中文 + 英语 + 阿拉伯语 | 6 张 | **60** |

### 4.5 异常与边界

| 场景 | 期望表现 |
| --- | --- |
| 未上传图片点开始 | 上传区抖动，不扣分、不提交 |
| 语种只剩 1 个仍尝试取消 | 标签抖动，保持选中，无语种为 0 的提交路径 |
| 张数/比例被取消到无选中 | 不允许（UI 层保证始终有 1 个选中） |
| 张数=1、语种=1 | 摘要显示「1 张 × 1 语种 · 共 10 积分」 |
| 余额不足 | 弹确认框并给出差额，确定跳充值中心 |
| 处理中重复点击 | 提交无效，不重复扣分 |
| 生成失败 | 原路返还积分并写入返还明细，提示用户可重试 |
| 上传中途移除图片 | 清空该图与上一次完成提示，摘要回到默认值 |

### 4.6 埋点需求（建议，待研发确认命名规范）

| 事件 | 触发时机 | 关键参数 |
| --- | --- | --- |

## 5. AI细节图 页面需求

### 5.1 页面定位

| 项 | 文案 |
| --- | --- |
| 页头标题 | AI细节图 |
| 页头副标题 | 放大材质与工艺细节，突出商品品质感 |
| 预览卡 tag | AI细节图 |
| 预览卡标题 | 细节放大不糊 |
| 预览卡副说明 | 材质工艺 · 清晰可见 |

**一句话定位**：上传 1 张商品图，围绕所选细节生成清晰可放大的特写图，用于详情页的品质证明。

### 5.2 字段清单

| # | 字段名 | 必填 | 组件类型 | 默认值 | 计费影响 |
| --- | --- | --- | --- | --- | --- |
| 1 | 商品图片 | 是 | 单图上传 | 空 | 无 |
| 2 | 突出细节 | 标注必填（实际可不选） | 多选标签 | 全不选 | 无 |
| 3 | 展示形式 | 否 | 单选标签 | 单细节展示 | 无 |
| 4 | 生成张数 | 是 | 单选（计数组） | 1张 | **倍数** |

> 字段顺序：商品图片 → 突出细节 → 展示形式 → 生成张数。

### 5.3 字段详解

#### 5.3.1 商品图片
- 规格同「3.4 上传组件规范」。

#### 5.3.2 突出细节（多选）
- 选项（8 项）：`材质纹理` / `工艺接缝` / `功能按键` / `品牌标识` / `包装细节` / `配件细节` / `内部结构` / `表面处理`
- 说明文案：`可多选，AI 将围绕所选细节生成特写；不选则自动识别`
- 规则：
  - 可多选、可全部取消；**全部未选时由 AI 自动识别最值得放大的细节**。
  - 不影响积分。
- 研发注意：同 4.3.2，字段名带必填星标但允许为空。

#### 5.3.3 展示形式（单选）
- 选项（2 项）：`单细节展示`（默认） / `多细节拼接展示`
- 说明文案：`单选，决定细节图的呈现方式；默认单细节展示`
- 规则：单选，始终保留 1 个选中；不影响积分；与「突出细节」为**正交关系**（选什么细节 × 怎么呈现）。

#### 5.3.4 生成张数（单选）
- 选项（3 档）：`1张`（默认） / `2张` / `4张`
- 说明文案：`按所选张数批量输出`
- 无「每种语种」限定语（细节图不含文案，无多语种维度）；说明小字中不出现单价话术。

### 5.4 计费与文案

| 项 | 内容 |
| --- | --- |
| 公式 | `积分 = 8 × 生成张数` |
| 单张单价 | 8 积分 / 张 |
| 底部摘要 | `N 张 · 共 X 积分` |
| 按钮徽标 | X（同摘要） |
| 完成提示（现状） | `已完成 · 已扣 X 积分`（通用文案，见第 7 节优化建议） |
| 明细描述（现状） | `生成扣减 · X 积分`（通用文案，见第 7 节优化建议） |

**计费示例**

| 突出细节 | 展示形式 | 张数 | 消耗积分 |
| --- | --- | --- | --- |
| 材质纹理 | 单细节展示 | 1张 | **8** |
| 材质纹理 + 工艺接缝 + 表面处理 | 多细节拼接展示 | 2张 | **16** |
| 全不选（自动识别） | 多细节拼接展示 | 4张 | **32** |

### 5.5 异常与边界

| 场景 | 期望表现 |
| --- | --- |
| 未上传图片点开始 | 上传区抖动，不扣分、不提交 |
| 细节/展示形式全不选或未选 | 允许提交（走 AI 自动识别），不阻断 |
| 张数被取消到无选中 | 不允许（UI 层保证始终有 1 个选中） |
| 余额不足 | 同 4.5，弹确认框并给出差额 |
| 处理中重复点击 | 提交无效，不重复扣分 |
| 生成失败 | 原路返还积分并写入返还明细 |

## 8. 现状差异与优化建议（研发排期时可一并处理）

以下为原型当前状态与建议目标的差异，**不影响本次功能上线**，但建议在开发时顺手对齐：

| # | 页面 | 现状 | 建议 |
| --- | --- | --- | --- |
| 1 | AI细节图 | 完成提示为通用文案「已完成 · 已扣 X 积分」 | 改为专属文案：`已生成 N 张细节图（突出细节 N 项 · 展示形式）· 已扣 X 积分` |
| 2 | AI细节图 | 扣分明细为通用文案「生成扣减 · X 积分」 | 改为 `AI细节图 · 突出细节 N 项 · 展示形式 · N 张 · X 积分` |
| 3 | AI卖点图 | 扣分明细已含比例，但未含卖点类型 | 可在明细中追加卖点类型摘要，便于用户回溯 |
| 4 | 两页 | 卖点类型 / 突出细节带必填星标，实际允许为空 | 二选一：去掉星标，或增加「默认全选自动识别项」；避免用户误解为必须选择 |
| 5 | 两页 | 上传为原型示意（点击即填充示例图），未接真实文件校验 | 研发需补齐：本地选择、格式/大小/尺寸校验、失败原因提示、异步上传与进度 |
| 6 | AI卖点图 | 卖点关键词无字数上限 | 建议限制 200 字并显示实时计数 |
| 7 | 两页 | 处理态为固定 1.9s 模拟 | 需接真实异步任务：排队/生成/完成/失败四态与进度反馈，失败自动退分 |
