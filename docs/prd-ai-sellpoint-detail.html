1. 名词约定

术语含义
积分平台统一计费单位，与生视频等业务共用同一余额账户与明细账户
张数单次提交生成图片的数量，档位固定 1 / 2 / 4
语种数卖点图特有维度，所选文案语言的数量，1～9
出图总量实际交付给用户的图片总数 = 张数 × 语种数（卖点图）／张数（细节图）
处理内容摘要底部操作栏左侧的动态文本，实时反映「本次将产出什么、扣多少分」

2. 背景与目标

2.1 业务背景

AI图片创作已上线换背景、白底图、去水印、局部消除、一键生图、电商套图等工具。但在「单品精修」链路中存在两个明显缺口：

  1. 上架缺卖点主图：商家手上有商品图，但没有文案能力，无法把「续航 48 小时、IPX7 防水」这类卖点排版成营销主图，跨境卖家还额外需要多语种版本。
  2. 详情页缺细节图：详情页要证明品质，需要材质、工艺、接缝等特写，但普通手机拍摄放大后糊、杂质多，无法直接上架。

因此新增两个工具页：AI卖点图（文字+图片合成能力）与 AI细节图（图像增强+局部特写能力）。

2.2 产品目标

目标说明
一次产出可上架的主图用户仅需上传 1 张商品图，即可得到带卖点文案的成品主图，无需设计能力
支撑跨境多语种场景卖点文案按目标市场语种输出，覆盖东南亚 / 中东 / 日韩等主力出海市场
细节图品质证明输出清晰可放大、可用于详情页的材质工艺特写

2.3 与其他工具的能力边界（避免重复建设）

工具边界
AI卖点图单品精修：围绕单商品做卖点文案排版，输出单张成品主图（可多张/多语种）
电商套图整店批量：按平台规范一次性输出整套上架图（含白底/场景/卖点/尺寸等模块）
一键生图批量粗加工：一次勾选多种类型批量出图，不做单类型深度精修
AI细节图细节特写：只做局部放大与细节呈现，不做文案排版
依赖关系：AI卖点图与电商套图的「卖点信息图」模块能力相似，前者为精修单图、后者为套图模块，需共用同一套文案生成能力，差异仅在输出规格与排版模板。

4. AI卖点图 页面需求

4.1 页面定位

项文案
页头标题AI卖点图
页头副标题自动提炼卖点文案，排版生成营销主图
预览卡 tagAI卖点图
预览卡标题一图讲清卖点
预览卡副说明多语种文案 · 排版上图
预览卡角标左：商品图（深色）／右：卖点成图（浅色）

一句话定位：上传 1 张商品图，AI 自动提炼卖点并排版成可上架的营销主图，支持多语种、多张批量输出。

4.2 字段清单

#字段名必填组件类型默认值计费影响
1商品图片是单图上传空无
2卖点类型标注必填（实际可不选）多选标签全不选无
3卖点关键词否多行文本（2 行）空无
4生图比例是单选标签1:1无
5生成张数是单选（计数组）1张倍数
6文案语种是（至少 1）多选标签中文倍数
字段展示顺序即为上表顺序（商品图片 → 卖点类型 → 卖点关键词 → 生图比例 → 生成张数 → 文案语种），不得调整（张数与语种相邻易混淆，已刻意把语种放最后）。

4.3 字段详解

4.3.1 商品图片

  • 规格同「3.4 上传组件规范」。
  • 上传后 AI 需识别商品主体、类目、主色调，作为文案生成与排版底图。

4.3.2 卖点类型（多选）

  • 选项（6 项）：核心功能 / 性能优势 / 材质工艺 / 设计亮点 / 使用场景 / 促销活动
  • 说明文案：可多选，AI 将围绕所选类型提炼卖点并排版上图；不选则自动识别
  • 规则：

- 可多选、可全部取消；全部未选时语义为「由 AI 自动识别卖点方向」，不阻断提交。 - 该字段不影响积分（卖点图走固定单价，不按类型数加价）。

  • 研发注意：字段名带必填星标，但业务上允许为空，实现时按「可为空，空 = 自动识别」处理，勿做前端强校验。

4.3.3 卖点关键词（选填）

  • 组件：多行文本，默认 2 行高度，可自适应。
  • 占位符：描述商品卖点，如「续航 48 小时 · IPX7 防水 · 一年换新」，留空则由 AI 自动提炼
  • 规则：填写时该内容优先级高于 AI 自动提炼；建议限制 200 字以内（原型未限制，研发需补充字数上限与实时计数提示）。

4.3.4 生图比例（单选）

  • 选项（5 档）：1:1（默认） / 4:3 / 3:4 / 16:9 / 9:16
  • 说明文案：1:1 平台主图 · 4:3 详情页横图 · 3:4 竖版主图 / 详情首屏 · 16:9 横幅 · 9:16 短视频封面
  • 规则：单选，始终保留 1 个选中（不可取消到无选中态）；切换不额外计费。

4.3.5 生成张数（单选）

  • 字段名带限定语：生成张数 + 灰字 （每种语种）
  • 选项（3 档）：1张（默认） / 2张 / 4张
  • 说明文案：可一次输出多张不同构图 或 卖点组合的商品图
  • 语义：每个语种各生成所选张数。例：选「2张 + 中文/英语」时，中文出 2 张、英文出 2 张，共 4 张。
  • 说明小字中禁止出现单价话术（如「单张 10 积分」），价格只在按钮徽标与摘要中体现。

4.3.6 文案语种（多选）

  • 字段名带限定语：文案语种 + 灰字 （可多选）
  • 选项（9 项）：中文（默认选中） / 英语 / 阿拉伯语 / 泰语 / 印尼语 / 越南语 / 韩语 / 马来语 / 蒙古语
  • 说明文案：按所选语言输出整套卖点图，按「张数 × 语种数」计
  • 字段头右侧实时计数：已选 N 个语种 · 共出图 N 张（共出图 = 张数 × 语种数）
  • 规则：

- 至少保留 1 个语种：取消最后一个时抖动提示并保持选中（不做弹窗）。 - 与视频翻译的语种口径保持一致。

4.5 异常与边界

场景期望表现
未上传图片点开始上传区抖动，不扣分、不提交
语种只剩 1 个仍尝试取消标签抖动，保持选中，无语种为 0 的提交路径
张数/比例被取消到无选中不允许（UI 层保证始终有 1 个选中）
张数=1、语种=1摘要显示「1 张 × 1 语种 · 共 10 积分」
余额不足弹确认框并给出差额，确定跳充值中心
处理中重复点击提交无效，不重复扣分
生成失败原路返还积分并写入返还明细，提示用户可重试
上传中途移除图片清空该图与上一次完成提示，摘要回到默认值

5. AI细节图 页面需求

5.1 页面定位

项文案
页头标题AI细节图
页头副标题放大材质与工艺细节，突出商品品质感
预览卡 tagAI细节图
预览卡标题细节放大不糊
预览卡副说明材质工艺 · 清晰可见

一句话定位：上传 1 张商品图，围绕所选细节生成清晰可放大的特写图，用于详情页的品质证明。

5.2 字段清单

#字段名必填组件类型默认值计费影响
1商品图片是单图上传空无
2突出细节标注必填（实际可不选）多选标签全不选无
3展示形式否单选标签单细节展示无
4生成张数是单选（计数组）1张倍数
字段顺序：商品图片 → 突出细节 → 展示形式 → 生成张数。

5.3 字段详解

5.3.1 商品图片

  • 规格同「3.4 上传组件规范」。

5.3.2 突出细节（多选）

  • 选项（8 项）：材质纹理 / 工艺接缝 / 功能按键 / 品牌标识 / 包装细节 / 配件细节 / 内部结构 / 表面处理
  • 说明文案：可多选，AI 将围绕所选细节生成特写；不选则自动识别
  • 规则：

- 可多选、可全部取消；全部未选时由 AI 自动识别最值得放大的细节。 - 不影响积分。

  • 研发注意：同 4.3.2，字段名带必填星标但允许为空。

5.3.3 展示形式（单选）

  • 选项（2 项）：单细节展示（默认） / 多细节拼接展示
  • 说明文案：单选，决定细节图的呈现方式；默认单细节展示
  • 规则：单选，始终保留 1 个选中；不影响积分；与「突出细节」为正交关系（选什么细节 × 怎么呈现）。

5.3.4 生成张数（单选）

  • 选项（3 档）：1张（默认） / 2张 / 4张
  • 说明文案：按所选张数批量输出
  • 无「每种语种」限定语（细节图不含文案，无多语种维度）；说明小字中不出现单价话术。

以下为原型当前状态与建议目标的差异，不影响本次功能上线，但建议在开发时顺手对齐：

#页面现状建议
1AI细节图完成提示为通用文案「已完成 · 已扣 X 积分」改为专属文案：已生成 N 张细节图（突出细节 N 项 · 展示形式）· 已扣 X 积分
